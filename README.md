# 🎉 Event Planner App – UI/UX Case Study

[🔗 View Figma Design](https://www.figma.com/design/Z6xxSkFIpmGAWCuAjsEH6r/Event-Planner?node-id=274-2654&m=dev)

## 📝 Overview

**Event Planner** is a smart and intuitive mobile app designed for non-professional users to plan events like weddings, engagements, birthdays, and more — with ease and clarity. This case study focuses on building a seamless user experience for event organization, from budgeting to guest and vendor management.

## ✨ Key Features

- 🧾 **Budget Tracker** – Monitor expenses and stay within financial limits
- 📋 **Guest List Manager** – Organize RSVPs with confirmed/declined tags
- 🛍️ **Vendor Booking** – Book photographers, caterers, decorators, and more
- 🔁 **Switch Events** – Plan and manage multiple events at once
- 📤 **Social Sharing** – Share tasks, updates, or plans with family & friends
- ⏰ **Event Reminders** – Never miss a deadline with timely alerts

## 🛠 Tools Used

- **Figma** – UI design, prototyping, and presentation

## 📌 Extra Notes

This project was part of a hands-on UI/UX practice challenge where I researched real user feedback, identified gaps in existing apps, and designed a practical solution. It allowed me to refine both my UX thinking and visual storytelling while solving real-world problems for casual event organizers.
